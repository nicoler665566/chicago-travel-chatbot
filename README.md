# WindyCityTrip | Travel Planning Chatbot

Demonstrate intent-driven travel assistance for Chicago.

## Technical approach

Use Rasa DIET intent classification, dialogue policies and Python custom actions with 20 flight listings, 10 hotels and 20 restaurants.

## Technologies

Rasa, Rasa SDK, Python, YAML

## Project materials

- Application source and configuration files in this repository.

## Getting started

From the repository root, configure a compatible Rasa environment, run `rasa train`, start `rasa run actions` in another terminal, and run `rasa shell`. Listings and reservations are static demonstrations, not live bookings; some responses are hard-coded.

For notebooks, use a compatible Python/Jupyter environment and install the imported libraries. Original environment-specific paths may need local adjustment.
